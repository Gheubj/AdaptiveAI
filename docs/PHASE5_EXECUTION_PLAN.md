# Phase 5 Execution Plan

Decision gate: **GO TO PHASE 5 WITH RESEARCH LIMITATIONS**. Phase 5 is not executed here.

The MVP should package the existing local research tool, not market an unproven adaptive-quality
advantage. Milestone 1 adds install/runtime checks, schema-validated configuration, registry hash
verification, actionable errors, dynamic localhost ports, and reproducible commands. Milestone 2
adds a persistent residency manager, switch hysteresis, streaming API responses, cancellation,
bounded queues, privacy-safe structured logs, and integration tests. Milestone 3 publishes an
experimental benchmark card, model/license instructions, threat model, and release checklist.

Research continues in parallel: preregister a complementary third-model criterion, seek approval
before any new weight download, recalibrate latency by task and expected output length using only
pre-inference features, and independently repeat the V2 protocol on a less templated licensed
panel. MVP success is safe reproducible local use; it is not a claim of universal routing gains.
