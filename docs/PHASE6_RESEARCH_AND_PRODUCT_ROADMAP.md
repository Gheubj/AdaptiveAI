# Phase 6 Research and Product Roadmap

Phase 6 is proposed, not started.

1. Independently validate V2 conclusions on a less templated, licensed held-out panel.
2. Preregister a complementary CPU model criterion; obtain download approval; measure oracle
   headroom before training routers.
3. Compare persistent multi-model residency, hysteresis, batching, and queue-aware routing under
   matched RAM/latency budgets.
4. Collect opt-in, privacy-preserving user feedback on installation, errors, workloads, and modes.
5. Add an optional cloud adapter only with explicit credentials, cost/privacy controls, mocks, and
   separate security review.
6. Prepare a scientific manuscript that separates engineering contributions from routing novelty
   and preserves negative/OOD results.
