# Next Routing Research Plan

Prompt-Aware Router V2 is not implemented in Phase 6G. Work that can proceed now: freeze schemas,
generate synthetic contract fixtures, validate provider identity joins, define preregistered metrics,
and exercise offline gateway traces whose provenance permits reuse. Training and comparative claims
require licensed row-level supervision, sufficiently matched prompt/model outcomes, predeclared
ID/OOD splits, cost/latency measurements for the target deployments, and an untouched final test.

xRouteBench and restricted RoutingCompendium sources require written permission or a clearly
applicable license. Live provider evaluation additionally requires owner-approved spend and a fixed
budget. Hyperparameters must use train/validation only; final test and ARC-AGI remain excluded from
selection. Baselines must include best single, deterministic constrained selection, and Phase 2/3
controls. Report uncertainty, calibration, quality, cost, latency, failures, and compute.
