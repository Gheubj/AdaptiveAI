# Phase 6B Execution Plan (Proposal Only)

Phase 6B is not authorized or implemented. Proposed entry gates:

1. Select one small source whose access, analysis, derived-use, attribution, commercial, and
   redistribution terms are recorded. Unknown redistribution remains blocked.
2. Freeze exact source version, retrieval procedure, checksum, model mapping, and adapter version.
3. Ingest a tiny metadata/aggregate pilot only; no paid calls, model download, crawling, or broad
   benchmark execution.
4. Run schema, missingness, identity, permission, and comparability reports before profile creation.
5. Review any alias/revision ambiguity manually; unresolved identities remain unresolved.
6. Produce versioned profiles, deterministic eligibility fixtures, and a bounded resource report.
7. Re-run full compatibility, lint, build, archive inspection, and install tests.

Stop conditions include unclear permission, mandatory notice not preserved, unresolvable exact
identity, incompatible metric semantics, resource budget breach, or any regression in v0.1.0
behavior. A successful pilot still would not establish a universal ranking or hardware-routing
superiority.
