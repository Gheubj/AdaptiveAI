# Phase 6C Execution Plan — Benchmark-Informed Routing Baseline V2

Phase 6C is proposed, not implemented. Entry requires a candidate pool with exact model/deployment
identity and comparable evidence. The present SWE-bench agent records alone do not meet that gate.

Proposed work:

1. Resolve a small model/deployment pool and freeze compatible evidence groups.
2. Measure evidence overlap, revision completeness, freshness, complementarity, and oracle headroom.
3. Preregister task mapping, train/validation/test boundaries, cost-quality estimand, abstention, and
   stop criteria.
4. Compare Fixed Strongest, Cheapest, task rules, benchmark-only prior, TF-IDF, and semantic controls.
5. Use matched per-instance outcomes; never interpret aggregate leaderboard scores as labels.
6. Evaluate ID/OOD/temporal/model-family generalization, calibration, uncertainty, latency, and cost.
7. Stop if identity/scaffold confounding, insufficient overlap, or no plausible headroom remains.

No cloud inference, training, or Phase 6C experiment is authorized by this plan.
