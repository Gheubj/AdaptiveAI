documentation fixes. Never include secrets or private prompts. Labels: `documentation`, `good first issue`.

## 2. Add a Windows PowerShell onboarding variant

Contribute a MockTransport contract for one OpenAI-compatible provider without network calls,
credentials or paid inference. Cover URL, model, usage, typed errors and disabled retry. Labels:
`provider`, `testing`, `good first issue`.

## 4. Improve installation error diagnostics

or `doctor` messages without adding telemetry. Labels: `developer experience`, `good first issue`.
