# Next Research Experiment

Phase 7.1 does not start this experiment.

After a successful separately authorized compatibility smoke, preregister a small matched study of
local and BYOK candidates on public, redistribution-compatible prompts. Freeze identities,
deployments, scoring, budgets, exclusions, seeds and uncertainty analysis before inference. Use a
new holdout, preserve failures, report provider/model drift, and separate compatibility evidence
from quality evidence.

Entry gates: explicit data permission, per-provider owner authorization, fixed maximum request
counts and spend, independently verified pricing, reproducible environment, and no final-test use
for hyperparameter selection. Primary outputs should be paired quality, latency, usage/cost and
failure rate with confidence intervals; the null result remains publishable. This is a proposal,
not Phase 8 authorization.
